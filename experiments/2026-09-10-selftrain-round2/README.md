# 2026-09-10-selftrain-round2 — does a second self-training round compound?

| | |
|---|---|
| **Status** | ❌ negative — one round is the recipe |
| **Date** | 2026-09-10 |

## Question

S4 ran **one** round of confidence self-training and took the target from **0.5611** to
**0.6135** (@0.5). The CBST literature reports compounding gains over 2–3 rounds: the
round-1 model is better on the target, so its pseudo-labels should be cleaner, so round 2
should improve again. Does that hold here?

**Why it matters:** rounds are the cheapest remaining lever — no new data, no new
architecture, just another pass. If they compound, the Jaipur transfer should run 2–3 rounds.
If they saturate or degrade, one round is the recipe and the extra compute goes elsewhere.

**Why now, and why fixed-threshold:** S6 established that a fixed confidence threshold in
**0.01–0.46** is a plateau (all within 0.023 IoU) while ratio-matching falls roughly linearly
and crosses below baseline near ratio 0.012. Round 2 therefore uses `--threshold 0.45`
directly rather than a ratio, which is also the policy that would be used blind on Jaipur.

## Predictions (before running)

**Target IoU @0.5: 0.615 – 0.645.** Reasoning: round 1 bought +0.052. A second round on a
better teacher should buy less, not more — the easy confident pixels were already captured,
and the remaining errors are the systematic ones the model is *confidently* wrong about, which
self-training cannot fix by construction. I expect **+0.00 to +0.03**, i.e. diminishing but
positive.

**Precision should rise, recall should be flat or fall.** At a fixed 0.45 threshold on a
better-calibrated teacher, the pseudo-labels get purer rather than more numerous.

**The failure mode to watch: confirmation bias / drift.** If round 2 lands *below* 0.6135, the
model is amplifying its own errors — the pseudo-labels have locked in round 1's mistakes. That
result would cap the recipe at one round and is worth as much as a gain.

**Pseudo-label foreground fraction is the leading indicator.** S4's teacher selected ~0.0059
of pixels. If round 2's teacher selects *substantially more* at the same threshold, confidence
has inflated without necessarily becoming more correct — the classic self-training pathology.

## Setup

Round-2 pseudo-labels generated by the **S4 checkpoint** at a **fixed 0.45** threshold, then
trained identically to S4: google-real + ign-pseudo, 30 epochs, checkpoint selected on
**source** val, reported on `ign_val` at a fixed 0.5 operating point.

The ign labels are never read during pseudo-labelling — only at evaluation.

```bash
python scripts/self_train_pseudolabel.py \
  --ckpt experiments/2026-09-10-solar-selftrain-conf/checkpoints/.../best.pth \
  --threshold 0.45 --out_dir data/bdappv_pseudo_r2/ign_train
python solar_panel/train_solar.py --train_dir data/bdappv_st_r2/train \
  --val_dir data/bdappv_split/google_val --epochs 30 --cache_ram --save_every 999
```

## Results

Checkpoint selected on **source** val, target reported at a fixed 0.5 operating point.

| | pseudo-label thr | source @0.5 | **target @0.5** | target P | target R | target best |
|---|---|---|---|---|---|---|
| S1 source-only | — | 0.8723 | 0.5611 | 0.741 | 0.698 | 0.5611 |
| **S4 round 1** | 0.4563 | 0.8745 | **0.6135** | 0.819 | 0.710 | 0.6165 @0.1 |
| **S7 round 2** | 0.45 (fixed) | 0.8708 | **0.6104** | 0.819 | 0.706 | 0.6134 @0.1 |

**Round 2 changed nothing: −0.0031 IoU, precision identical to three decimals.**

**Prediction scorecard — missed, and in the direction that matters.** Predicted 0.615–0.645
(+0.00 to +0.03); actual **0.6104**, just below the range and marginally below round 1. I also
predicted precision would *rise* and recall stay flat; precision was **unchanged** (0.819 →
0.819) and recall moved −0.004. The pre-registered failure mode — round 2 landing below round
1 through error amplification — did not occur either: this is not drift, it is a null result.

## Interpretation

**Self-training saturates after one round here. It does not compound.** The −0.0031 gap is far
inside seed noise, so the honest statement is *no measurable change*, not *worse*.

**The mechanism is visible in the pseudo-labels, and it was the leading indicator I set in
advance.** Round 1's teacher selected ~0.0059 of target pixels as foreground; round 2's teacher,
at essentially the same threshold, selected **0.00574**. Nearly the same pixels, so nearly the
same training set, so nearly the same model. A better teacher did not produce a *different*
pseudo-label set — it produced the same one.

**Why that is not surprising in hindsight.** A fixed threshold selects what the model is
already confident about. Round 1 improved the model mostly on examples it was *already* getting
right, which does not move the confident set. The pixels that would add information are exactly
the ones both rounds are confidently wrong about, and no amount of self-labelling reaches them —
the method cannot teach itself what it does not already suspect.

**This contradicts the CBST literature's reported compounding gains**, and the S6 result
suggests why: those gains are usually reported with a *ratio* policy that forcibly injects new
foreground each round. That policy is precisely what S6 measured as harmful here (crossover
between ratio 0.008 and 0.012). So the mechanism that generates multi-round gains in the
literature is the same one that destroys performance on this domain gap. **Rounds and ratio
are not independent choices** — taking the safe threshold policy also forfeits compounding.

**Budget consequence.** Round 2 cost ~2.6 GPU-hours for zero gain. On Jaipur, where nothing can
be measured, running extra rounds would have felt like diligence and produced nothing.

## Decision

- [x] **One round. Fixed threshold ~0.45.** That is the Stage-2 self-training recipe.
- [x] **Do not run round 3.** Two consecutive rounds with a flat result is enough.
- [ ] If multi-round is ever revisited, the lever must be *diversity* of the pseudo-label set
      (augmentation-consistency, or a second teacher), not another pass at the same threshold.

## Threats to validity

- Same C1 caveat: every BDAPPV crop contains a panel, so precision is optimistic in absolute
  terms; relative comparisons across rounds share the caveat exactly.
- One seed. S4 vs round 2 differing by <0.02 would not be separable from seed noise.
- Round 2's teacher was selected on *source* val, as in every other arm — so a round-2 gain is
  not explained by target-side model selection.
