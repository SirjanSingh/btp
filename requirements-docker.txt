# requirements-docker.txt — deps to install ON TOP of nvcr.io/nvidia/pytorch:24.05-py3

# Differs from requirements.txt because the base image changed:
#   requirements.txt  assumed pytorch/pytorch:2.1.2-cuda11.8  (torch 2.1.2, cu118)
#   this file         assumes nvcr.io/nvidia/pytorch:24.05-py3 (torch 2.4.0a0, cu124)
#
# We switched base images because 24.05 is ALREADY PULLED on this node, and `/` has
# ~1.8 GB free — there is no room to pull or build anything else. See run_docker.sh.
#
# NEVER pip-install torch/torchvision here — the base image's build is CUDA-matched
# and NVIDIA-optimised. Installing torch from PyPI would silently replace it.

#   pip list | grep -i opencv        # should show ONLY opencv-python-headless
